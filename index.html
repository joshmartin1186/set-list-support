Set List

Build a varied set list from your own songs, then see the whole set on one screen.

How it works

  1. Songs tab: add your songs under categories (Ambient, Singer-Songwriter, anything you like). A chord chart and lyrics are optional.
  2. Set tab → ⋯ → New Set: pick a length and drag the mix sliders. The shares always add up to 100%. Set List builds the set.
  3. Songs you haven't played in the longest time are picked first, and the running order avoids your recent sets. Every set is saved with its date under History.
  4. Tap any song for its chart. Use Previous and Next to walk the set, and Back to return to the list.

Add songs from a computer

Plug in your iPhone, open Finder, select the iPhone and open the Files tab. Drag song files onto Set List. Open the app and they are added to your library.

  • One file is one song. The file name is the title, or put {title: My Song} on the first line.
  • Chords can sit above the lyrics, inline like [Am], or on a line such as Verse: G F C G. A file with no chords is treated as lyrics.
  • Put files in a folder to choose the category: Ambient/Slow Orbit.txt.
  • Add {duration: 4:30} on its own line to set a song's length.
  • Supported: .txt .chordpro .cho .crd .pro, plus .json in the library format.

You can also use Songs → + → Import from Files on the phone.

Questions

Where is my data? Only on your iPhone. There is no account and nothing is uploaded. If you delete the app, your songs and sets go with it.

The set is shorter than I asked for. The categories you gave a share to don't have enough songs. Add songs, or lower that category's share.

Song lengths. New songs default to 4:00. Edit a song to set its real length so sets come out the right size.
